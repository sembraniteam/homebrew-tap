# homebrew-tap

Official Homebrew tap for [sembraniteam](https://github.com/sembraniteam).

## Usage

```sh
brew tap sembraniteam/tap
```

## Formulae

| Formula                 | Description                                     | Version |
|-------------------------|-------------------------------------------------|---------|
| [mpkg](Formula/mpkg.rb) | Generate static HTML for Go vanity import paths | v0.3.0  |

## Installation

### mpkg

```sh
brew install sembraniteam/tap/mpkg
```
